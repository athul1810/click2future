# Repository preferences

- Use the user's configured Git identity for commits. Check the author and committer before pushing. Do not add assistant or bot attribution or co-author trailers.
- Write in plain, direct language. Avoid promotional slogans, generic filler, and claims that have not been tested.
- Do not use em dashes. Use normal punctuation and ASCII hyphens for ranges.
- Apply the same writing style to documentation, commit messages, issues, pull requests, and milestones.
- Keep task owners unassigned unless the user specifies an assignment.
- Keep only the 14 November 2026 submission deadline. Do not add intermediate milestones or task dates unless the user asks.
