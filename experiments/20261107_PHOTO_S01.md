# PHOTO-S01: native StreamForce feasibility on A40

This is an external pretrained-model integration probe. It has no held-out
physics score and cannot promote any original Click2Future model.

Use the official source revision `57a15e95eca25bbbb32d6ac6322ba3e12fd45083`,
the released EMA state, the first declared point-force CSV example, its manual
caption, and seeds 0, 1, 2 and 3 in that order. Repeat seed 0 once afterward.
Retain every output and failure. No optional captioner, tensor quantization,
layer truncation, attention-mask alteration or sampler substitution is allowed.

The user-supplied original archive has SHA-256
`e2b112d1c1f1f09f84a8ed305c9ab7778335cc843b47434e81ea9af2942a4efb`.
The original 61,486,967,303 bytes remain intact locally. A streamed inference
archive omits only the non-EMA `generator` dictionary. All 1,278 EMA tensor
names, shapes, strides, storage bytes and float32 precision are preserved.
Its 30,743,458,292 bytes have SHA-256
`df7db8615d76016cc2089cb9753b1dfea256333d719d44935947bfea6523fac3`.
This is a local identity, without a publisher-provided reference digest.

Before inference, verify the external source inventory, each selected base
artifact against pinned official Hub identities, and the uploaded EMA archive.
Record the loader/probe hashes, project revision, library versions, hardware,
input/action record, native sampler settings and raw/MP4 identities.

Run one A40 with at most eight CPUs, 30 GiB host memory and three hours.
Native output is 81 RGB frames, 832x480 at 16 fps, using the released four-step
causal student and its rolling-forcing inference. Measure startup separately,
then per-seed wall time, first-chunk time, GPU peak and host peak. Keep the
repeat's raw-pixel maximum/mean difference and exact-equality result. Numerical
repeatability and visual/control quality are separate findings.

The functional gate requires all four declared outputs with the native shape,
dtype, finite source output and matching archived hashes. Inspect all four at
fixed times, retaining weak action responses and deformations. A failure or
OOM remains a result; it does not justify silently shrinking resolution or
changing the attention implementation. Compare engineering costs to the
existing fallback only with the different native contracts stated.
